# 创投智联

创投智联是一套连接项目、资本、FA、政府招商部门与产业资源的创投协同平台。

平台围绕“发现机会、了解主体、发起对接、推进授权、留下记录”展开，帮助不同角色在同一个信息和协作空间内完成项目发现、机构筛选、区域招商和内容阅读。

当前版本是一个可持续迭代的产品型 MVP，已经具备用户端、管理后台、API 服务和权限领域包的基础能力。

## 平台服务对象

| 角色 | 主要需求 |
| --- | --- |
| 项目方 | 展示项目、寻找投资机构、管理 BP 访问权限 |
| 投资机构 | 浏览项目、筛选行业和阶段、申请查看项目材料 |
| FA 机构 | 协助项目融资、推进机构沟通和材料授权 |
| 政府招商部门 | 了解项目和产业方向，发起区域落地对接 |
| 普通用户 | 浏览公开项目、机构、行业和创投内容 |
| 平台运营 | 管理主体认证、项目审核、对接线索和审计记录 |

## 核心平台功能

### 1. 投融资项目库

聚合公开项目和融资机会，支持按行业、地区、融资阶段等维度了解项目信息。

- 项目名称、行业、地区、融资阶段和融资需求
- 项目公开摘要和匿名展示
- 项目详情和项目方介绍
- 项目收藏、最近浏览和关注记录
- 项目提交与审核基础流程
- 支持后续围绕项目状态、投资偏好和对接进度继续扩展

### 2. 公司库

从企业主体角度查看公司信息，帮助用户了解企业所在行业、业务方向和区域分布。

- 公司名称、主体类型和一句话介绍
- 行业标签和业务方向
- 地区与总部信息
- 公司列表、关键词搜索和基础筛选
- 公司详情和收藏入口

### 3. 创投机构库

集中展示 VC、PE、FA 等创投服务主体，方便项目方和产业方了解机构类型与关注方向。

- 投资机构、FA 机构等主体分类
- 投资领域和偏好方向
- 机构所在地和主体信息
- 机构列表、关键词筛选和收藏
- 机构画像与更多机构数据的扩展入口

### 4. 政府对接

连接项目方与区域招商部门、产业园区和政府联系人，服务项目落地和产业招商需求。

- 按地区和产业关键词查找招商联系人
- 查看招商部门、联系人职务和负责方向
- 提交招商对接需求
- 由平台运营人员进行线下匹配和跟进
- 记录对接需求，支持后续扩展线索管理

平台不直接公开所有联系方式，敏感信息通过申请和运营审核机制进行管理。

### 5. 研究报告

沉淀一级市场、产业趋势、融资方法和区域招商相关内容。

- 研究专题和报告摘要
- 市场观察、招商指南和融资方法等内容分类
- 专题阅读和继续阅读入口
- 为后续在线全文阅读、下载和内容订阅预留空间

### 6. 创投电报

将融资、并购、产品、机构和股权变化整理成简短、连续的创投信息流。

- 按时间查看创投动态
- 按电报类型阅读内容
- 关键词搜索
- 查看单条电报详情
- 支持分享单条信息

### 7. 行业图谱

从行业、项目、机构和区域几个维度观察产业结构，帮助用户快速找到关注赛道。

- 人工智能、新能源、生物医药、先进制造等行业分类
- 行业项目数量和热度展示
- 行业节点切换
- 细分方向和产业链标签
- 为后续接入融资事件、企业关系和政策数据预留扩展能力

### 8. 产品服务

围绕创投协作中的常见需求，提供平台服务入口和后续产品方向。

- 项目曝光
- 资本对接
- 政府招商
- 研究支持
- 企业会员与数据订阅方向

产品服务页面用于说明平台能力和服务边界，具体对接仍以平台运营流程为准。

### 9. 账号与身份

平台根据不同参与角色提供相应的浏览、收藏、提交和授权能力。

- 登录与注册
- 普通用户、项目方、投资机构、FA、政府招商等身份选择
- 账号中心
- 收藏和最近浏览
- 项目方提交项目与 BP
- 机构主体认证和状态展示

## BP 授权与协作闭环

平台对项目材料采用申请、审批和授权访问机制，核心流程包括：

1. 用户浏览项目公开信息和 BP 摘要。
2. 已认证的投资机构、FA 或政府招商组织提交查看申请。
3. 项目方或具备项目管理权限的 FA 审核申请。
4. 审批时可以设置有效期和访问范围。
5. 服务端在访问时重新校验组织、权限、有效期和撤回状态。
6. 访问记录写入审计日志，并生成追踪编号和水印信息。

这个流程用于降低项目材料外泄风险，并让项目方保留对敏感资料的控制权。

## 数据与安全原则

- 公开信息与受授权信息分层展示
- 以主体认证和组织身份作为权限基础
- BP 文件遵循最小权限原则
- 申请、审批、访问和撤回均保留记录
- 访问敏感材料时生成水印和追踪信息
- 平台管理员不能绕过项目方授权直接读取受保护 BP
- 演示数据与真实业务数据保持清晰边界

## 当前产品边界

当前版本重点验证创投门户、项目发现、主体目录、政府对接和内容入口的产品结构。部分行业、机构、研究和电报内容仍使用本地演示数据，真实数据源、内容运营和更完整的主体认证能力将按产品阶段逐步接入。

平台当前更适合用于产品演示、业务流程验证和内部协作，不代表所有模块已经达到正式商业运营的完整度。
